Wollix

Woven UI for C.

Wollix is a header-only, immediate-mode UI toolkit for C11 that includes a text editor, with backends for Raylib, SDL3 and the web. The same C code runs as a native desktop application through Raylib or SDL3, and in the browser through WebAssembly; this page is the dashboard demo's web build, drawn on a canvas. Wollix can also be called from C++.
